# PROMPTS.md

## Project: SkyMiles Frequent Flyer Portal

### Prompt 1 — Test-Driven Development
Create acceptance tests for member enrollment, searching, invalid inputs,
empty states, loading indicators, accessibility, and XSS protection.
Write the tests before implementing the application.

### Prompt 2 — Dashboard UI
Build a clean, monochromatic, responsive frequent flyer portal
using HTML, CSS, and JavaScript.

### Prompt 3 — Member Management
Implement member enrollment, unique member IDs, search by ID,
name and email, and friendly empty states.

### Prompt 4 — Flight Bookings
Implement flight booking forms, airport-code validation,
booking status, and a recent bookings table.

### Prompt 5 — Miles and Rewards
Implement miles balances and redemption with validation
to prevent negative balances and invalid transactions.

### Prompt 6 — Error Handling
Add loading indicators, form error messages, safe storage handling,
and graceful error states for failed operations.

### Prompt 7 — Security and Accessibility
Prevent unsafe HTML rendering, add accessible labels,
keyboard navigation, focus indicators, and ARIA announcements.

### Prompt 8 — Analytics
Log simulated analytics messages after successful primary actions.

### Prompt 9 — Final Quality Checks
Run automated tests, ESLint, accessibility checks, and a production
build. Fix failures before deployment.
